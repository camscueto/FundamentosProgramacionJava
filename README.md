Ejercicio 2
Validador de Edad en Java ( Ejercicio2)
Programa sencillo en Java que solicita la edad por consola y clasifica al usuario según su rango de edad (menor de edad, mayor de edad, adulto mayor o edad no válida).

📋 Características
Lectura de datos por consola usando Scanner.

Validación de entradas negativas.

Estructura de control condicional ( if-else if-else).
