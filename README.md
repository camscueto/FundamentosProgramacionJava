# Fundamentos de Programación en Java 

## Descripción del proyecto

Este repositorio contiene tres ejercicios prácticos desarrollados en Java, cuyo propósito es aplicar y fortalecer los conceptos fundamentales de programación. A través de diferentes problemas, se trabajan variables, entrada y salida de datos, operadores aritméticos, estructuras condicionales y métodos.

## Ejercicios desarrollados

### Ejercicio 1. Calculadora de promedio
Programa que solicita el nombre de un estudiante y tres calificaciones, calcula el promedio y presenta los resultados en pantalla.

**Conceptos aplicados:**
- Variables de tipo `String` y `double`.
- Entrada de datos mediante `Scanner`.
- Operaciones aritméticas.
- Salida de información con `System.out.println()`.

### Ejercicio 2. Validador de edad
Programa que solicita la edad del usuario y determina su clasificación según el rango ingresado.

**Conceptos aplicados:**
- Variables de tipo `int`.
- Entrada de datos mediante `Scanner`.
- Estructuras condicionales `if`, `else if` y `else`.
- Evaluación de condiciones lógicas.

### Ejercicio 3. Cuadrado de un número
Programa que solicita un número entero y calcula su cuadrado mediante un método independiente.

**Conceptos aplicados:**
- Creación y utilización de métodos.
- Parámetros y argumentos.
- Tipo de retorno `int`.
- Instrucción `return`.
- Operaciones matemáticas.

## ⚙️ Requisitos

- Java Development Kit (JDK) instalado.
- Editor de código o IDE compatible con Java.
- Terminal o consola para compilar y ejecutar los programas.

## Ejecución

Desde la carpeta raíz del proyecto, compilar y ejecutar cada ejercicio:

**Ejercicio 1**
```bash
javac src/Ejercicio1.java
java -cp src Ejercicio1
```

**Ejercicio 2**
```bash
javac src/Ejercicio2.java
java -cp src Ejercicio2
```

**Ejercicio 3**
```bash
javac src/Ejercicio3.java
java -cp src Ejercicio3
```

## Objetivo de aprendizaje

Fortalecer las habilidades de lógica y resolución de problemas mediante la implementación de programas básicos en Java, comprendiendo la estructura de un programa, el manejo de datos, las operaciones, las decisiones y la reutilización de código mediante métodos.

Proyecto académico desarrollado como parte del proceso de aprendizaje de los fundamentos de programación y del lenguaje Java.
